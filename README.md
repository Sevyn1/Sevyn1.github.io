# XDetect website

A static informational website for XDetect, built with HTML/CSS/JavaScript and third-party Bootstrap/jQuery-era assets. This repository contains the website, not a machine-learning detector or hardware implementation.

## Preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000. Pages include the homepage, team, contact, and support information.

## Portfolio context

Treat this as an older web example. Bundled vendor libraries are not original application code; retain their license headers. Authorship of template components should not be implied. The stronger current backend/AI examples are the separate Transaction Lab and Reverse Dictionary repositories.

## Verification boundary

No backend, ML inference endpoint, automated test suite, or form-delivery service is established by this source. External assets and delivery behavior need separate verification before a deployment claim is made.
